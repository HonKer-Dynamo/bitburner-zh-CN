Bitburner（蒸汽/Steam 版）简体中文汉化补丁
=========================================
适用版本：Bitburner 3.0.1（Steam 版，构建 3162fd2）
（其他版本请勿使用：安装脚本会检测版本号，不符会自动拒绝，不会改动你的游戏）

【功能】
- 游戏界面：侧边栏、状态、终端、编辑器、活动脚本、创建程序、派系、义体、
  公司、城市/旅行/犯罪、潜入行动、帮派、刃行者、分身、移植、企业、Hacknet、
  编程契约、斯塔内克的馈赠、IPvGO 围棋、赌场、股票市场、选项、存档管理等全部汉化
- 终端：48 个命令的输出、错误与 help 帮助全文汉化
- 运行时报错：Netscript 脚本错误、.exe 程序输出、离线收益弹窗等汉化
- 帮助文档：游戏内 Documentation 的基础/进阶/入门 FAQ 全量、
  NS API 全部函数摘要 + 常用函数详情页
- 教程与游戏内文学文件（.lit）：新手教程 29 步全部、33 篇文学全量
- Steam 原生菜单（文件/编辑/视图等）与系统对话框
- 合计约 1 万条词条；词条以官方开源仓库 tag v3.0.1 逐文件核对翻译

【保留英文的内容】（有意设计，方便查攻略/写脚本）
终端命令名（ls/run/connect…）、Netscript API 函数名、服务器主机名、
文件名与 .exe 程序名、股票代码、代码块与示例代码。

【安装】（先完全退出 Bitburner）
1. 双击 install.bat（或在 PowerShell 里运行 .\install.ps1 -GameDir "你的游戏目录"）
2. 安装器会自动寻找 Steam 库中的 Bitburner；找不到时会提示你手动指定路径
3. 启动游戏即生效。若界面仍是英文：确认游戏完全退出后重启一次；
   仍无效则按 F12 打开开发者工具，Console 输入 BitburnerZH.stats() 查看词条数（应为数千）

【卸载】
- 双击 uninstall.bat；或
- Steam 中右键 Bitburner → 属性 → 已安装文件 → 验证游戏文件完整性（自动还原全部官方文件）

【对游戏的影响】
- 不修改、不重打包游戏核心 main.bundle.js（5MB 游戏代码保持原样），
  翻译通过运行时注入的字典实现：字典缺失或异常只会退回英文，不会损坏游戏
- 不影响存档、Steam 云同步与成就（安装器只动 index.html 与 5 个主进程文案文件，
  且全部先做 .bak-zh 备份；主进程文件只在与官方原版逐字节一致时才会替换）
- 若你曾自行修改过 main.js/menu.js 等文件，安装器会跳过这些文件并告知（界面汉化不受影响）

【已知局限】
- NS API 深层详情页（约百余页长描述）未完全翻译，函数摘要行已全部翻译
- 极少数含内联代码/插值的长句可能中英混排
- 游戏更新到新版本后，本补丁会失效（安装器会拒绝在非 3.0.1 上安装，防止出问题）；
  可等新版补丁，或自行按下方方法更新字典

【补充词条 / 二次修改】
- 汉化引擎与字典都在 resources/app/dist/zh-locale/ 下，全部为纯文本 JS：
  * localize.js      翻译引擎（一般无需改）
  * dict-*.js        字典文件（文件头注释含各自的覆盖/未覆盖清单）
  词条格式见任何字典文件内示例：
    BitburnerZH.exact({"英文整句": "中文"})
    BitburnerZH.frag({"带空格的片段": "中文片段"})
    BitburnerZH.patterns([[/^整句模板(\S+)X$/, "$1 中文 X"]])
    BitburnerZH.names({"专名": "中文专名"})
  改完后重进游戏即生效。若某个文件写出语法错误，只有那个文件失效，游戏照常运行。
